# WhiteDNS Android 1.6.14

Fix CottenMax startup with long account domains generated by WhiteDNS Server Management. Connection and scan configurations now reserve enough initial DNS query-name space for the Max handshake, including standby domains, shortened payload labels and optional label-count jitter.

The required capacity is calculated when the engine configuration is generated. Saved profiles and higher custom QNAME budgets are preserved. Normal mode retains its existing behavior.

For panel-managed Max connections, update the server to WhiteDNS Server Management 0.10.0 as well. Existing domains, encryption keys and subscription URLs remain valid. The client core remains pinned to `7db7b73658c791cce62300d29647e4d369d6e1e4`; this release fixes the app's configuration adapter.

Validated with rendering regression tests and the Android unit suite; CI builds and verifies signed APKs. Physical-device and restricted-network confirmation remain separate from these checks.
